\# Employee Salary Prediction



\## Project Overview



This project predicts employee salary using Machine Learning algorithms based on employee information such as age, gender, education level, job title, and years of experience.



\## Dataset



The dataset contains the following features:



\- Age

\- Gender

\- Education Level

\- Job Title

\- Years of Experience

\- Salary



\## Machine Learning Algorithms



The following regression algorithms were implemented and compared:



1\. Linear Regression

2\. Decision Tree

3\. Random Forest

4\. Gradient Boosting



\## Model Evaluation



The models were evaluated using:



\- MAE (Mean Absolute Error)

\- RMSE (Root Mean Squared Error)

\- R² Score



\### Best Model



\*\*Gradient Boosting\*\*



Best R² Score:



\*\*0.8882\*\*
